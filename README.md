CMAPSS Predictive Maintenance – Remaining Useful Life (RUL) Prediction

This project applies exploratory data analysis and regression modeling to predict Remaining Useful Life (RUL) using the NASA C-MAPSS turbofan engine dataset. The goal is to identify degradation patters from sensor data and build predictive maintenance models.

Key Features
- Performed EDA and feature selection using statistical analysis and correlation heatmaps
- Built Multiple Linear Regression and Random Forest Regression models
- Compared model performance using RMSE and MAE
- Identified key sensor variables most correlated with engine degradation

Methods and Tools
- Data Processing: Pandas, NumPy
- Visualization: Matplotlib, Seaborn
- Modeling: Multiple Linear Regression, Random Forest Regression
- Evaluation Metrics: RMSE, MAE

Results Summary
- Correlation analysis revealed high-impact degradation sensors
- Random Forest outperformed linear regression, capturing nonlinear degradation trends
- Demonstrated a complete predictive maintenance modeling pipeline

Skills Demonstrated
- Data Cleaning & Feature Engineering
- Exploratory Data Analysis
- Regression Modeling
- Model Evaluation and Comparison
- Predictive Maintenance & Time-Series Reasoning
